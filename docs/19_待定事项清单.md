## 二、闭环规则

1. 任一待定项确认后：① 改代码 → ② 更新本表状态与结论 → ③ 在 `CHANGELOG.md` 追加一条闭环记录 → ④ 同步 `20_功能描述文档` / `21_测试文档` 中相关描述。
2. 若裁决导致接口字段或路径变化，必须走 `13` §9 变更流程（PM 批 → 双端同步 → 版本号递增），禁止「我先改了你跟上」。
3. 本期（v2 开发迭代）结束前，T-01 / T-02 / T-03 / T-10 四项必须闭环，其余可带入 `22_下一步需求文档` 的二期 backlog。
