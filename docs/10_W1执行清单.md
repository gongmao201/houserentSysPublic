> 用途：2026-11-03 ~ 11-09 第一周的可执行手册。7 件事，每件都有"怎么做 / 怎么验 / 做不成怎么办"。

## 事项 1 · 依赖 spike（BE，4 小时硬时限）

### 1.1 为什么它是第一优先

`jjwt 0.9.1` 依赖 `javax.xml.bind.DatatypeConverter`，**JDK11+ 已移除该类**。不换版本，登录接口一调就 `NoClassDefFoundError`。这不是"可能有问题"，是"一定崩"。

### 1.2 执行步骤

```bash
# 0) 开分支，保证可回退
git checkout -b spike/jdk17-boot2718

# 1) 记录基线（升级前）
java -version                                  # 期望 17.x
mvn -v                                         # 期望 Maven 3.9+
mvn -q dependency:tree > docs/spike/deps-before.txt

# 2) 改 pom：parent 版本
#    2.5.5 → 2.7.18

# 3) 改 pom：删掉硬编码的 spring-tx（让 Boot 管理）
#    删除 <dependency> org.springframework:spring-tx:5.3.9 </dependency>

# 4) 改 pom：MyBatis starter
#    1.3.0 → 2.3.2

# 5) 改 pom：JWT 收敛到一套
#    删除 io.jsonwebtoken:jjwt:0.9.1 与 com.auth0:java-jwt:3.4.0
#    新增 jjwt-api / jjwt-impl / jjwt-jackson 三个 0.11.5

# 6) 改 pom：fastjson 修 CVE
#    1.2.71 → 1.2.83

# 7) 编译
mvn -q clean package -DskipTests

# 8) 起服务（JVM 额外参数，fastjson 在 JDK17 需要）
java --add-opens java.base/java.lang=ALL-UNNAMED \
     --add-opens java.base/java.math=ALL-UNNAMED \
     -jar target/hrent-0.0.1-SNAPSHOT.jar

# 9) 验收（三条都要过）
curl -s http://localhost:8080/actuator/health          # {"status":"UP"}
curl -s -X POST http://localhost:8080/login \
     -H "Content-Type: application/json" \
     -d '{"loginName":"admin","password": "<DEMO_PASSWORD>"}'     # 返回 token
curl -s http://localhost:8080/house/list?page=1&size=5  # 返回房源列表
```

### 1.3 验收标准（缺一不可）

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 编译 | `BUILD SUCCESS`，无 `javax.xml.bind` 相关报错 |
| 2 | 启动 | 无 `BeanCreationException`，日志出现 `Started ... in X seconds` |
| 3 | 健康 | `/actuator/health` 返回 `UP` |
| 4 | 登录 | 能签发 JWT，且能用该 token 访问受保护接口 |
| 5 | 业务 | 房源列表返回数据（说明 12 个 XML mapper 至少主链路加载成功） |

### 1.4 做不成怎么办（PM 4 小时内拍板）

| 卡点 | 退路 |
|---|---|
| `jjwt` 0.11.5 API 改动太大，2 小时改不完 | 保留 0.9.1，**加 `javax.xml.bind:jaxb-api:2.3.1` + `jaxb-runtime` 依赖**，不改代码 |
| MyBatis starter 2.3.2 与现有 XML 冲突 | 回 2.2.2；仍不行则回 1.3.0 + 手动配 `SqlSessionFactory` |
| fastjson 1.2.83 仍报反射异常 | 加 `--add-opens`；再不行回 1.2.71，**把"换 Jackson"提到 W3 而不是 W10** |
| 4 小时仍起不来 | **JDK 留 8、Boot 留 2.5.5**，只加 Redis / Flyway / OpenAPI / 新模块。老板要的是"性能优化"，不是"JDK17" |

### 1.5 产出

`docs/spike/spike-report.md`：六个依赖 × 四列（现状 / 动作 / 结果 / 结论），一页纸，W1 周五评审用。


## 事项 3 · 备案与类目核验（PM，W1 D1 启动）

### 3.1 类目核验（0.5 小时，先做这个，它决定后面所有事）

1. 登录微信公众平台 → 设置 → 基本设置 → 服务类目 → "添加类目"
2. 搜索"房地产"、"房屋租赁"、"租房"
3. 记录：个人主体可选类目里**有没有**这些；若只能选企业类目，则**提审路径彻底关闭**

**产出**：类目树截图 + 一句话结论（"个人主体可/不可开通租房类目"）。

> 若不可（大概率）：本期交付形态锁定为"现场演示 + 开发版工程"，不承诺任何形式的上架分发。这条要写进验收口径。

### 3.2 备案（1–3 周，W1 必须提交）

| 步骤 | 时长 | 材料 |

## 事项 6 · 造数立项（PM 立项，QA + BE 执行，W9 前完成）

### 6.1 规模修正：60 套，不是 200 套

v2.1 写 200 套，实际算一下就知道不可行：200 套 × 5 图 = 1000 张图，人工不可能在 12 周内产出且涉及版权。

| 项 | 数量 | 说明 |
|---|---|---|
| 房源 | **60 套**（3 个小区 × 20） | 足够撑满列表分页、筛选、推荐 Top10 |
| 图片 | 80 张（60 主图 + 20 图池复用） | **用 ImageGen 生成**，避免盗图 |
| 租约 | 30 条（10 条已退租、15 条生效中、5 条已到期） | 支撑评分与账单向导 |
| 评价 | 50 条（其中 20 条带图） | 支撑评分分布与详情页 |
| 账单 | 90 条（30 租约 × 3 个月） | 支撑账单列表与逾期态 |

### 6.2 分工

| 谁 | 做什么 | 人日 |
|---|---|---|
| PM | 定 3 个小区、房型分布、价格区间 | 0.5 |
| QA | 写 CSV 模板（房源/租约/评价/账单四张表） | 1 |
| BE | 写 `seed.sql` 或 `seed.py` 导入脚本 + 幂等（可重复跑） | 1 |
| MP | 用 ImageGen 生成 80 张图（统一风格：原木/白墙/采光） | 1 |
| QA | 验收：每张列表页有数据、每套房有 0–5 条评价、每个租约状态都覆盖 | 0.5 |

### 6.3 硬约束

- 图片**不得使用网上真实房源图**（版权 + 真实性风险）。
- 房源地址用虚构小区名（"云栖花园"这类），不映射真实地址。
- 手机号用 `138****0001` 这类测试号，不填真实号码。
