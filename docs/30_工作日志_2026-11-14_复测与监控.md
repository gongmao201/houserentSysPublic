## 三、时区 / 字符集

| 层 | 现状 |
|---|---|
| 库 | `default_collation_name = utf8mb4_general_ci`（V9 修正了建库时的 0900 默认） |
| 表 | 25 张业务表全部 `utf8mb4_general_ci`，V9 断言“非 general_ci 表 = 0” |
| 连接 | Hikari `connection-init-sql: SET time_zone='+08:00'`（连接建立即固定会话时区） |
| JVM / 序列化 | `-Duser.timezone=Asia/Shanghai`（start.cmd / start.sh 均注入）、Jackson `time-zone: Asia/Shanghai` |

说明：CLI 直连的 `@@session.time_zone` 仍显示 `SYSTEM`，这是命令行连接自己的会话；应用连接的时区由连接池初始化语句固定，`/actuator/health` 的 db 探针能通过也说明该 init SQL 已成功执行。
