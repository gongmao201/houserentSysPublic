## 2. JWT 双验期

### 2.1 规则

| 场景 | 验签密钥 | 过期判定 | 结果 |
| --- | --- | --- | --- |
| 新 token（含 `vt=2`），未过期 | `token.secret` | 严格按 `exp` | 通过 |
| 新 token，已过期任意时长 | `token.secret` | 不放宽 | 拒绝 |
| 新 token 但用老密钥签名 | 主密钥验不过 → 老密钥验过 | — | 拒绝（防降级） |
| 老 token（无 `vt`），未过期 | 主密钥或 `token.legacy-secret` | 严格按 `exp` | 通过 |
| 老 token，过期 ≤ 7 天 | 主密钥或 `token.legacy-secret` | `exp + legacy-grace-days` | 通过 |
| 老 token，过期 > 7 天 | — | — | 拒绝 |

配置项（`application.yml`）：

```yaml
token:
  secret: ${TOKEN_SECRET:${JWT_SECRET:}}
  expire-days: 7
  legacy-secret: ${TOKEN_LEGACY_SECRET:}
  legacy-grace-days: ${TOKEN_LEGACY_GRACE_DAYS:7}
```

兼容性：`TokenUtils.configure(secret, expireDays)` 两参重载保留，历史单测与离线调用不受影响。

## 3. 租约状态机与退租确认

### 3.2 接口

| 方法 | 路径 | 允许角色 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| POST | `/api/v2/lease/{id}/terminate` | 租客/房东/管理员 | `actualEndDate` | 0→2 或 1→2；返回 `reviewWindowUntil = actualEndDate + 30 天` |
| POST | `/api/v2/lease/{id}/expire` | 房东/管理员 | 无（body 可空） | 0→1 |
| POST | `/api/v2/lease/{id}/cancel` | 租客/房东/管理员 | `reason` | 0→3 |

- 并发控制：`transitionLease(id, from, to, actualEndDate, version)` 用 `status=#{from} AND version=#{version}` 更新，影响行数 0 → 业务码 409。
- 审计留痕：每次成功流转写 `lease_log`（`from_status`/`to_status`/`operator_id`/`remark`）。
- 幂等/重复：同状态重复调用返回 `409 重复操作不再受理`；白名单外返回 `409 状态流转非法：X → Y`（终态追加“该状态为终态，不可再流转”）。
- 响应新增 `allowedNext`，前端据此置灰按钮。

## 4. 评分 API 与上架审核

### 4.1 8 项权重与通过规则

| 项 | 权重 | 核心项 |
| --- | --- | --- |
| photoReal 照片真实 | 0.20 | 是 |
| addressVerified 地址可核验 | 0.20 | 是 |
| facilityMatch 设施一致 | 0.15 | 否 |
| priceReasonable 价格合理 | 0.15 | 否 |
| contractUploaded 合同已上传 | 0.10 | 否 |
| safetyChecked 消防/安全 | 0.10 | 是 |
| depositRuleClear 押金规则清晰 | 0.05 | 否 |
| noComplaint 无投诉记录 | 0.05 | 否 |

- 计分：`score = Σ(命中权重 × 5)`，保留 2 位小数，满分 5.00。
- 通过：`score ≥ 3.00` 且 3 个核心项全部通过 → `passed=true`，房源 `hrent_house_resource.state` 由 0 置 1；未通过保持 0（UC-01 要求“核验不通过保持审核中”）。
- 缺项处理：8 项未全部给出布尔值时返回 `400` 并列出 `missing`，避免“漏勾”被当作 false 静默计分。
- `state` 更新 SQL 带 `state=0` 条件，已租（2）/已审核（1）不会被降级。

### 4.2 贝叶斯展示分

```
bayesian = (C × m + Σs) / (C + n)，C = 3，m = 4.0
display  = 0.4 × officialScore + 0.6 × bayesian   （officialScore 为空时取 4.0）
```

- 冷启动（n=0、无核验）恒为 `4.0`；已抽为 `public static BigDecimal computeDisplayScore(...)`，便于单测。
- 与 `docs/14` FR-RATE-05 的示例 `(5×4.0)/5` 存在 C 值差异，实现沿用 `RatingService` 既有常量 C=3（`docs/19` T-06 待定项）；改口径只需动 `PRIOR_C`/`PRIOR_M`。
