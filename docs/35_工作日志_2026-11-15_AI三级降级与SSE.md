## 2. 降级链

```
请求
 │
 ├─ 规则抽取：区域 / 预算 / 房型 / 标签
 │     └─ 命中 ≥3 字段 → 直接检索（不调模型）
 │
 ├─ 命中 <3 → [第 1 级] local
 │     云托管 → 花生壳(vicp.fun) → 本机 Ollama qwen2.5:3b
 │     超时 3s / 连接失败 / HTTP 5xx / 坏 JSON
 │
 ├─ [第 2 级] deepseek
 │     https://api.deepseek.com/v1/chat/completions
 │     超时 8s / 余额不足 / HTTP 5xx
 │
 └─ [第 3 级] rule
       零外部依赖：规则匹配 + 模板理由
       接口始终 HTTP 200
```

实现要点：

| 点 | 处理 |
|---|---|
| 未配置端点 | `isConfigured=false`，直接跳下一级，不发请求 |
| DeepSeek 无 key | 同上跳过，不产生 401 噪声 |
| 超时 | `connectTimeout` + `socketTimeout` 都设为配置值，避免只限连接不限读 |
| 返回判定 | HTTP 200 且 `choices[0].message.content` 非空才继续解析；解析为空意图/空理由也算失败 |
| 失败日志 | `WARN` 记录 provider + 原因（截断 160 字），不打印 api-key |
| 兼容 | Apache HttpClient 4.x，`pom.xml` 未新增依赖，JDK8 目标可运行 |

## 3. 配置

```yaml
ai:
  mode: auto          # auto / local / deepseek / rule
  local:
    enabled: true
    endpoint: "${AI_LOCAL_ENDPOINT:}"      # 例：https://xxx.vicp.fun
    timeout-ms: 3000
    model: "qwen2.5:3b-instruct-q4"
  deepseek:
    enabled: true
    endpoint: "https://api.deepseek.com/v1/chat/completions"
    api-key: "${DEEPSEEK_API_KEY:}"
    timeout-ms: 8000
    model: "deepseek-chat"
```

- 端点可填基址（自动补 `/v1/chat/completions`）、`.../v1` 或完整地址。
- `mode=local` / `deepseek` 只走指定一级，失败直接落 rule，便于演示对比。
- `mode=rule` 完全不建外部请求，适合无网环境。

## 4. 规则抽取与模型补全

| 步骤 | 行为 |
|---|---|
| 规则正则 | `2500以内/预算2500` → `budgetMax`；`两房` → rooms；`天河区` → region |
| 规则标签 | 养猫/宠物→`pet`、地铁→`metro`、电梯→`elevator`、采光/朝南→`sunny` |
| 触发模型 | region/budget/rooms/tags 合计命中 <3 |
| 合并规则 | 模型结果只补空字段，不覆盖显式 `filters`；tags 去重追加 |
| 模型输出校验 | region ≤64 字；预算 0–20 万元（元转分）；rooms 1–6；tags 仅白名单 |
| 响应标识 | `mode=llm/rule`；`intent.source=local/deepseek/rule`，前端只看不判断 |

模型失败时保留规则已抽到的字段，不会因为模型 500 把整个请求变成 500。

## 5. SSE 理由增强

`POST /api/v2/ai/reason/stream`（需登录，最多 10 个 `houseId`，`text/event-stream`）：

| 事件 | 时机 | data |
|---|---|---|
| `meta` | 建流 | `{total,mode:"stream"}` |
| `template` | 立即，每个房源一条 | `{houseId,reason,source:"rule"}` |
| `reason` | 模型增强成功 | `{houseId,reason,source:"local/deepseek"}` |
| `done` | 结束 | `{source,mode,total,enhanced}` |

设计原因：`docs/00` 要求推荐理由首字 <3s，而模型可能 3s/8s 才回；先推模板帧保证首屏，再推增强帧替换。模型全挂时只发 `template + done(enhanced=0)`，连接不会断。

实测帧（本地 mock，enhanced=1）：

```text
event:meta
data:{"total":1,"mode":"stream"}

event:template
data:{"houseId":"HR20260101000001","reason":"1500 元，匹配你的结构化条件","source":"rule"}

event:reason
data:{"houseId":"HR20260101000001","reason":"AI 增强：天河两房，3200 元内，近地铁可养宠","source":"local"}

event:done
data:{"source":"local","mode":"llm","total":1,"enhanced":1}
```
